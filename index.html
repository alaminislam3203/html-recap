Frequently Asked Questions (Dropdown Accordion - <details> tag)

Why are we learning only HTML first?

HTML is the skeleton or framework of a web page. Learning HTML before styling with CSS and adding interactivity with JavaScript keeps the website's semantic structure correct.


What is the purpose of the 'alt' attribute in the image tag?

The 'alt' (Alternative Text) describes the image in writing if it fails to load for any reason, or for blind users who rely on screen readers.


What is the difference between <ul> and <ol>?

<ul> is an unordered list (bullet points) where order or sequence is not needed. On the other hand, <ol> is an ordered list (1, 2, 3...) where the steps are kept in sequence, one after another.
